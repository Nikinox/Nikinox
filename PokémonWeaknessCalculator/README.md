This is a Pokémon matchup chart, super useful to find type matchups.

However, it's not the best way to find dual-type matchups, sure you can look to websites like this https://pokemondb.net/type/dual but it's just an endless amount of charts.

## What this program fixes
It allows you to calculate quickly the matchups againist every type.

Sure, you can watch the Pokémon infos somewhere else, but there are some combos that never appeared for now.
